# CV-Builder 📄✨

Um gerador de currículo e portfólio web interativo de alto padrão (Premium), projetado para funcionar perfeitamente em duas frentes: como um site responsivo elegante com suporte a temas Escuro/Claro, e como um currículo impresso ou PDF em tamanho A4 de alta fidelidade e contraste perfeito.

Este projeto foi desenvolvido com foco em código limpo, sem dependências externas, utilizando o melhor do desenvolvimento Web nativo.

---

## 🚀 Funcionalidades Principais

* **Modo de Edição Dinâmico (Modo Live-Editor):** Permite editar qualquer informação diretamente na página em tempo real. Basta clicar e digitar.
* **Adição e Remoção de Conteúdo:** Adicione dinamicamente novas experiências profissionais, formações acadêmicas, competências (técnicas e comportamentais) e cursos com um clique. Itens em branco ou não preenchidos são removidos automaticamente ao salvar.
* **Persistência de Dados Local (`localStorage`):** Todas as alterações feitas no modo de edição são salvas localmente no navegador, permitindo recarregar a página ou voltar mais tarde sem perder o progresso.
* **Segurança de Elementos:** Proteção contra exclusão acidental de marcadores e formatações de tags durante a digitação.
* **Alternador de Temas (Dark/Light Mode):** Design moderno com transições suaves e uso avançado de variáveis CSS, efeitos de glassmorphism e micro-animações.
* **PDF Pixel-Perfect (Estilização de Impressão):** Uma folha de estilos dedicada (`@media print`) otimiza automaticamente o currículo para caber perfeitamente em exatamente **uma página A4**, ocultando painéis de controle, botões de ação e aplicando alto contraste nas fontes para garantir legibilidade absoluta para recrutadores.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica para melhor acessibilidade e SEO.
* **CSS3 (Vanilla):** Sistema de variáveis HSL dinâmicas, animações e responsividade completa.
* **JavaScript (Vanilla):** Lógica nativa de manipulação do DOM, manipulação de eventos delegados e persistência de dados local.

## 📦 Como Usar Localmente

1. Clone este repositório:
   ```bash
   git clone https://github.com/SeuUsuario/CV-Builder.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd CV-Builder
   ```
3. Abra o arquivo `index.html` em qualquer navegador moderno.
